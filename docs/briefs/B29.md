## What to do

1. **Synchronous throws from `push`.** `src/messaging/outbox.ts` (`deliver`) treats any synchronous throw from `emailer.push` as "never reached a pool" (row back to `queued` for the restore hold, `failed` otherwise). Read `push` (`src/messaging/email.ts:597-623`) and `dispatch`. Make the contract true by construction: everything from the moment a message is handed to a pool must report failure as a rejected `result` promise, never a synchronous throw, so only pre-pool code (the `refuse` hook, settings, server selection) can throw. Add a test at the emailer boundary that a failure after hand-off rejects instead of throwing. If it already holds, show why in the PR and add the test anyway.
2. **`claimOne` guard.** The #75 test cannot reach the `UPDATE` guard in `src/messaging/sends.ts` (`claimOne`), because the `SELECT` on one connection already finds no queued row. Decide: if the guard is unreachable on a single connection with no concurrent writer, say so in a code comment and close the line; do not add a test that pretends to cover it.
3. **Migration 18 edge.** A hand-edited non-object bounce rule makes migration 18 fail and stops startup (it is transactional and a snapshot is taken first). Make the migration skip rows whose rule is not a JSON object (`json_type(...) = 'object'`) so a bad hand edit cannot block an upgrade; test it with a version-17 database holding such a rule.
4. **B24 test gaps.** In `test/users/legacy-b24.test.ts` (or a sibling): after the `count: 0` rewrite, post one bounce through the bounces API and check the action fires and a bounce row is recorded; log in as a user the migration changed (an account with password login off keeps API-key access and has no TOTP prompt; an API user authenticates with its key).
5. **Path-type check.** In `test/contract/openapi.ts`, the path-type check throws if a path entry is not an operation with a parameter list. Make it report a named failure instead (skip `parameters`/`summary`-style path keys, fail with the path and key for anything unexpected).
