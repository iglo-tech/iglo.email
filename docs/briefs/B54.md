## Source

These are review findings about tests that can fail without a product defect, and a few coverage gaps. Read the linked review comments with `gh pr view <n> --comments` and verify each item against `main` first. Change tests and test helpers only. If a test exposes a real product defect, stop, report it, and fix it only if it is small.

## Items

1. **Zero-yield waits on real I/O** (#96 r1). `test/media/storage.test.ts:201` loops 20,000 zero-length yields while a 24 MiB write runs, and `test/messaging/send-rate.test.ts:373` waits on a real local SMTP sink with iteration limits as low as 50. This is the same latent bug B49 fixed in `drive` (`docs/perf/B49-drive-bound.md`): bound by wall time and keep a diagnostic error. Reuse the B49 approach. Where it fits, import the shared wait helper rather than copying it.
2. **Restarts reuse a just-freed port** (#101 r1). Restarts in `test/contract/owned.ts`, `test/worked-example/harness.ts`, `test/webhooks/crash.ts` and one bootstrap test start again on the port the previous process just released, without the retry in `test/serve-port.ts`. Route them through `serve-port`.
3. **Process hygiene** (#101 r1):
   - two timeout paths kill a server without waiting for it, so they must reap;
   - `test/scheduler/crash.ts` now hides server stderr after a successful start, so print it on failure;
   - add a comment to `test/serve-port.ts` that adding `reusePort` to `Bun.serve` would break both the retry and `listensOn`.
4. **`test/bootstrap/cli.test.ts:300`** once exited 1 instead of 0 on SIGTERM under parallel load (#98 r2). Find out why: a shutdown race, a drain deadline, or a stderr assertion. Fix the cause. If it is a product shutdown bug, report it.
5. **MCP test 16** (#97 r1): add the scheduled-campaign case. Clearing `send_at` on a scheduled campaign moves it to draft, checked via GET.
6. **SNS tunnel** (#99 r1): add a test that a certificate for the wrong host is refused through the tunnel. Remove the upgrade-test helpers that duplicate bootstrap/`owned.ts` helpers, and import them instead.
