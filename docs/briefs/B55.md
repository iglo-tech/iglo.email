## Items

1. **A partial backup left in a swapped-away folder.** If a parent folder is swapped (renamed away or replaced by a symlink) after the partial directory `.iglo-email-backup-partial-*` was created, the refusal cleanup removes by path. That path no longer points at the partial, so the partial (0700, holding a database copy, manifest and uploads, all 0600) stays where the swapped parent went. Record the partial directory's device and inode when it is created. On cleanup, remove it only if a directory with that device and inode is found at the expected path. Otherwise, warn with the partial's last known path so the operator can remove it. Do not search the filesystem for it.
2. **A raw `ENOENT` while copying.** When a parent is swapped during the copy, the copy step fails with a raw `ENOENT`. Map it to the existing "changed meanwhile" refusal message.
3. **Concurrent backups sharing a newly created parent.** Two backups can share a parent folder that one of them created. That one may remove the folder while it is empty, just before the other writes into it, and the second then fails with a raw error. Make the second backup recreate the folder or retry once, and make removal tolerate a folder that another process has started using. `rmdir` fails on a non-empty folder, so treat ENOTEMPTY and EEXIST as "leave it" without a warning.
4. **A spurious warning after a successful publish.** After a successful publish, a later step that throws produces a harmless "kept: it is not empty" warning. Cleanup must not run after a successful publish. Check the flags in the `try`/`finally` around :550.

## Tests (through the CLI and `createBackup` hooks, as `test/backup/backup.test.ts` does)

1. A parent renamed away through the `available` or `beforePublish` hook after the partial exists: the backup refuses with "changed meanwhile", not a raw `ENOENT`. Either the partial is removed by device and inode, or the warning names its path; assert which one happens.

3. A forced failure after publish (through a hook) gives no "kept: not empty" warning.
