## 1. The sleep sweep (B118c item 7)

AGENTS.md says time-dependent behaviour is tested by advancing the injected clock, not by sleeping. #206's body lists the 108 files that still call `Bun.sleep` or poll a fixed number of times (about 251 lines).

- **Sleep that waits for a state:** replace it with a wait on that state. Use `until`, `untilProgress`, an event, or the injected clock.
- **Sleep that is the thing under test:** keep it, with a one-line reason. For example, a real-time deadline in a compiled-executable test.
- **Fixed-count poll loop** (`for (let i = 0; i < 50; i++) { …; await Bun.sleep(20) }`): replace it with `until` on the state, which fails by name when progress stops.
- **The PR:** report the counts before and after, and a table of each kept sleep with its reason.

Work file by file in an order that keeps each commit reviewable: one directory per commit. Run that directory's tests after each commit.
