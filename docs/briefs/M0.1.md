## Required behavior

- Bun >= 1.4, TypeScript, native ESM, Bun package manager and `bun.lock`.
- `@/` imports throughout, including tests; no barrels or framework. Keep startup state local and pass parsed configuration to the server.
- The CLI supports `serve`, `--help`, and bootstrap flags `--port`, `--host`, `--data-dir`, `--root-url`. Environment equivalents are `IGLO_EMAIL_PORT`, `IGLO_EMAIL_HOST`, `IGLO_EMAIL_DATA_DIR`, `IGLO_EMAIL_ROOT_URL`; flags take precedence. Document defaults and validate invalid values clearly. Use port 9000, host `127.0.0.1`, data directory `./data`, and a root URL derived from host/port when none is provided. These are bootstrap defaults, not stored settings.
- Recognize initial-admin environment inputs `IGLO_EMAIL_ADMIN_USER` and `IGLO_EMAIL_ADMIN_PASSWORD` without logging or returning them. User creation waits for M1.3; do not create a placeholder user store or require credentials just to run `/health`.
- `--install`, `--upgrade`, `--config` (including `--config=...`) and `--new-config` exit unsuccessfully with a clear explanation pointing to `docs/design/01-scope.md`. Unknown flags and commands fail clearly too.
- `bun build --compile` creates `dist/iglo.email`. The executable runs independently of the checkout and serves `/health` with the upstream status, JSON envelope and content type.
- Handle SIGTERM and SIGINT by closing the server. Application output contains only errors and things needing attention; help/version CLI output is fine.
- Pin development dependencies for TypeScript/Bun types, oxlint and oxfmt as needed. No runtime dependency is needed for this task.
- CI installs with the frozen Bun lock, checks formatting/lint/types, runs tests and builds the executable. Renovate handles updates. No Dependabot, Docker distribution or community files.
- A test of the compiled executable launches it from a temporary directory, checks `/health`, then stops only that child process. Use bounded readiness checks and process cleanup; no sleeps for domain-time tests. Cover CLI/env precedence and the rejected legacy flags through the CLI boundary. Do not read source files or assert on private implementation details.

## Acceptance

Expose and document these commands:

```sh
bun install --frozen-lockfile
bun run format:check
bun run lint
bun run typecheck
bun test
bun run build
bun run check
```

`bun run check` must include formatting, lint, type checks, behavior tests and the compile check without accidentally running an unbounded server. Tests must actually exercise the compiled executable from outside the checkout. Include the acceptance results in the PR and explain which reference checks are deferred until the harness tasks.
