## 1. Timing dependencies (release-gate watch items)

1. `test/contract/owned.ts:34`, `withProduction`: the compiled server's lifetime equals the 30 s test timeout instead of ending before it, so a slow readiness outlives the test. This is the likely source of the unattributed error in full runs. End it through the test's own abort before the test timeout, and show whether the unattributed error stops.
2. `test/bootstrap/cli.test.ts:114`: remove the fixed 3 s kill timer. The per-test CLI budget from B118a already kills child processes in time.
3. `test/messaging/plain-executable.test.ts:306`: replace the absolute 200 ms limit with a comparison inside the same run.
4. B118a r2 backlog:
   - The `query-limits` deadline test needs both exports to start within 1 s; restore a status check that names that case.
   - The release retry's final error leaves out the child's port-in-use message and the attempt count.
   - A child started at the very end of the budget can escape the kill, by a few ms.
   - The budget test adds a fixed 9 s.
5. `test/campaigns/runner/measure.ts:473` and `:416`: the harness counts the 20 double opt-in confirmations as campaign mail (investigation in PR #205, comment 7118177164). Count only messages that carry `X-Listmonk-Campaign`, and assert that exactly the 20 confirmations are the others.
6. `test/e2e/specs/editor-containment*` fails 2 tests on macOS, on main too:
   - use `ControlOrMeta` where it uses `Control+a`/`Control+x`;
   - make the click beside the image land at a position computed from the image's box.
7. The `Bun.sleep` and fixed-count poll sweep. AGENTS.md says time-dependent behaviour is tested by advancing the injected clock, not by sleeping. About 300 call sites remain. Replace each sleep that waits for a state with a wait on that state (`until`, an event or the clock). Keep a sleep only where it is the thing under test, with a one-line reason. List the counts before and after in the PR. If the sweep is too large for one PR, finish items 1–6 and 8 first, push, and report the remaining files to the lead.
