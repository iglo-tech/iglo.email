## Behavior

1. **Bounces:** list with filters, source and campaign links, paging, bulk delete and blocklist, a bounce's `meta`. The Mailgun source appears like any other. Provider text in `meta` is stored data and renders as text.
2. **Media:** gallery, upload, search, delete, copy URL. `thumb_url` is the original where no thumbnail exists, so the gallery sizes images in the page. Serving rules from M3.5 stay: nothing is rendered inline in the admin page from an unsafe type, an SVG included. A refused root (D64) shows the API's reason. The fragment replaces the M4.3 dialog in the campaign form.
3. **Import:** upload, parameters, progress polling, log display, stop, reset. Polling is bounded and stops when the import ends and when the page is hidden. A refused file shows the API's message, including the webhook budget.
4. **Forms:** the public subscription form generator for lists, with its copyable HTML. The generated HTML escapes list names and points at the configured root URL.
5. **Permissions:** each route gives `adminPage` the permissions its endpoint needs. Nav filtering is not authorization.
6. **Safety:** bounce sources and meta, media file names, import log lines and list names are escaped everywhere. File names cannot break out of an attribute or a copied snippet.
