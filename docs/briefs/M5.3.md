## Behavior

1. **Definitions API** (`GET/POST /api/sequences`, `GET/PUT/DELETE /api/sequences/:id`, `PUT /api/sequences/:id/status`).
   - Validate every field in the 05 table: trigger event name; `trigger.where` and step conditions through M5.2 `validate`, with `canUseSql` from the caller's `subscribers:sql_query`; `exit_on`; `reentry`; `list_id`, required and existing when any step is marketing; durations; `kind`; `template_id`, existing and of a suitable kind; `on_false`; `cap_policy`; `max_late` defaults.
   - Steps keep stable IDs across edits. Removed steps become `deleted` and are never hard-deleted while referenced.
   - Status changes `draft`/`active`/`paused`/`archived`. Archiving exits active enrollments with `sequence_archived`.
   - Bounded sizes: name, number of steps, condition size.
2. **Triggers and exits** in the event transaction (05 Events API, steps 2–3, in that order).
   - Exit active enrollments of active sequences whose `exit_on` contains the event (`event:<name>`).
   - Then start enrollments for active sequences whose trigger matches. `trigger.where` is evaluated against the event and subscriber with M5.2, inside the transaction and without a child process. If a `where` contains `sql`, reject it at save time for triggers unless you can evaluate it safely here; document the choice.
   - Respect reentry (`never`, `after_exit`, `always` replacing a running one) and the 7-day trigger eligibility.
   - New enrollments get `step_id` = first active step and `due_at = occurred_at + wait`.
   - Return the real `{started, ended}`.
3. **Enrollments API** (`GET /api/enrollments` with filters and paging, `GET /api/enrollments/:id`, `POST /api/enrollments` manual enroll that respects reentry unless explicitly forced, `DELETE /api/enrollments/:id` cancel with `manual`).
   - Concurrent triggers and manual enrolls for the same subscriber and sequence can't create two active enrollments.
4. **Subscriber deletion** cascades as the schema says. Unsubscribe and blocklist exits are atomic with the state change.
