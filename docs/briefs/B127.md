# B127: operator views show sequence and transactional mail, not only campaigns

Branch `task/B127-operator-views`. PR title "B127: operator views for sequence mail". Read `docs/briefs/_B97-common.md` first (container `oven/bun:1.4.5`, reference recipe, file rules, task-PR acceptance = the whole `ci.yml` check job with one valid `bun run check`; decision records appended at the END of `09-decisions.md`). Source: the first adopter's scenario and visual audit of main 08ac50f (53 real sends, 8 step tests, 219 screenshots at 1280 and 390 px). For any ported route or mail you change, read pinned upstream (GitHub, 6fcd95f) and list resulting differences in `07-api-and-ui.md` with reasons.

## Items

1. The subscriber page shows Campaigns/Views/Clicks 0/0/0 although sequence sends exist, and the dashboard says "Messages sent 0". Count all sends (campaign, sequence, tx) where the label is generic, or add sequence/tx counts beside campaign ones; label what each number counts.
2. The subscriber's Sends tab has no subject or sequence column; there is no admin page for the global send log (API only, `GET /api/sends`). Add subject, kind (campaign/sequence/tx), sequence and step, status and skip reason (B116) columns, and an admin "Sends" page over `GET /api/sends` with filters the API supports.
3. `external_id` is not shown on the subscriber page nor searchable. Show it; make the subscriber search match it exactly (use the existing API filter if one exists; otherwise add `external_id` to the search the admin uses without changing listmonk's query-API contract).
4. A cap-deferred enrollment shows only "Waiting for step 1 … 27 Nov"; show "held by frequency cap until …".
5. A step skipped as `late` shows a green "Completed"; show "Skipped (late)" in a neutral or warning style, and every other skip reason likewise.

6. B116 follow-ups (adopter check and review r1 of PR #175): the subscriber Events tab's "Sequences not started" column shows `1: subscriber_blocklisted, …`; show each sequence's name linked to it and a readable reason through i18n ("blocklisted", "suppressed after a data wipe"), with the label in every bundled locale, not only `en.json`. The campaign skip reason is `unsubscribed` whenever a skipped subscriber is not blocklisted, which mislabels a member who confirmed during an opt-in campaign (no longer unconfirmed) and one whose membership was deleted: name those accurately (for example `membership_changed`), documented in D131's place in `04-sending.md` and the OpenAPI enum. Correct the "no log line" comment in `src/campaigns/runner/runner.ts` that sits below the changed-subscriber attention log.
7. Subscriber page at 390 px (pre-existing): the tab row (View … Sends) is about 560 px wide, so the page scrolls sideways and the header/body render narrower than the viewport; in card mode the event JSON is right-aligned. No horizontal page scroll at 390 px; JSON left-aligned.

Use the existing admin view patterns (server TSX, Alpine/Oat). No new client framework.
