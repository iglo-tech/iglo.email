## 1. Export mail has no per-subscriber throttle

12 POSTs to the export route gave ten 200s then 429, and 10 "Your data" mails to the victim; each extra IP gets another 10 a minute, at the operator's SES reputation. Throttle data-export mail per subscriber with the existing opt-in mail throttle (`createThrottle`, same window and limit as opt-in mail), in addition to the IP limit. Over the limit: the same response as a success (no oracle), no mail. Test: N requests from several simulated client addresses send at most the throttle's allowance of mails (count in the sink, advance the injected clock to show it resets).

## 2. Personal public pages lack hardening headers

`/m/…/unsubscribe/…?manage=true` (shows the name; forms carry UUIDs) sends no `Cache-Control: no-store`, no `frame-ancestors`/`X-Frame-Options`, no `Referrer-Policy`. Add `Cache-Control: no-store`, `Referrer-Policy: no-referrer` and `Content-Security-Policy: frame-ancestors 'none'` (merged with any existing CSP) plus `X-Frame-Options: DENY` to every HTML response under `/m/*`, `/subscription/*` and `/campaign/*` (and any other public page that shows subscriber data; audit), through the shared public shell/response helper so no route can miss them. Test each route family for the headers.

## 3. Private webhook targets allowed by default

`webhooks.block_private_addresses` defaults to false; webhooks to `127.0.0.1:9000`, `169.254.169.254` and Docker service names were accepted and a signed POST reached an internal container. D122: the default becomes **true** for new installs and for installs that never set it (an explicitly stored false stays false: the operator chose it). Add a step to the operations "Deploying behind a reverse proxy or PaaS" checklist next to trusted proxies, and to the settings docs. Check that the blocking covers IPv4/IPv6 private, loopback, link-local (incl. 169.254.169.254), unique-local, and names resolving to them at delivery time (DNS rebinding: resolve once and connect to the checked address), and that redirects stay unfollowed. Tests: default install refuses a loopback/link-local/private target at registration or delivery (whichever the design does today) and a name resolving to a private address; explicit false allows; an upgrade with a stored false keeps it.
