## JSX contract

Keep it simple: synchronous typed components, intrinsic tags, fragments, nested arrays, text/numbers, omitted null/undefined/boolean children, attributes and void tags. Bun compiles the TSX; ordinary imports use @/ aliases, including copied browser modules after narrow import adaptation. No barrel/re-export layer except the exact automatic-runtime entry point the compiler requires.

Text and attribute values escape by default, including ampersand, angle brackets and quotes. Do not double-trust ordinary strings returned from components or interpolate arbitrary objects as HTML. raw() is an explicit trusted-markup boundary, cannot be impersonated by a plain object, and cannot bypass attribute escaping. Reject invalid tag/attribute names and unsupported values rather than generating malformed markup. Handle boolean DOM attributes, data-/aria- attributes and Alpine attributes without treating data/aria false as an absent boolean DOM attribute. No React-style function event handlers.

Test rendered results through isolated HTTP fixtures compiled from actual TSX, not unit assertions on private renderer functions or source text. Cover nested components/fragments, arrays/conditionals/void elements and hostile values in text, attributes and trusted/raw boundaries. The renderer does not turn an arbitrary URL or Alpine/JavaScript expression into safe code: shells must control attribute names/expressions and validate URL contexts. Serialize the browser config/i18n bootstrap as script-safe JSON (including </script>, <, &, U+2028/U+2029); never insert arbitrary JSON strings into executable HTML.
